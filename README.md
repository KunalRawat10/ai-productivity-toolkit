# AI Productivity Toolkit (Prompt Engineering & Workflows)

A Python toolkit implementing production prompt engineering techniques with small language models (SLMs).

## Features
- **Deterministic JSON Extraction:** Enforcing zero-shot schema constraints without heavy LLM fine-tuning.
- **Executive Summarization:** Automated context compression pipeline for technical literature.
- **Code Debugger & Refactorer:** Automated syntax and logic flaw detection using role-conditioned system prompts.
- **Outreach Automation:** Value-first cold communication drafting.

## Installation & Usage
```bash
pip install -r requirements.txt
python toolkit.py
